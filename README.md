# Pilot Kit Box PCB 贴片助手

用于 Pilot Kit Box PCB 手工贴片的浏览器工具。选择板卡版本，对照 PCB 焊盘图和 BOM 信息找料、定位、贴装并记录进度，也可以在开工前按清单备料。

页面使用静态 HTML、JavaScript 和 JSON，可在本机预览或部署到静态网站托管服务。库存 CSV 在当前浏览器中读取。

## 打开页面

在贴片助手目录启动本地服务：

```sh
python3 scripts/local_inventory.py --port 8000
```

打开终端显示的预览地址。已有进度保存在原访问地址时，可用 `--host` 和 `--port` 指定与原来相同的回环主机名和端口，再使用原地址访问。

页面通过 `fetch` 加载板卡 JSON，需要通过 HTTP 或 HTTPS 访问。直接双击 `index.html` 可能被浏览器的本地文件跨源限制拦截。

页面默认使用中文。可在版本选择页、操作栏或打开的清单中选择 English；界面、BOM 说明与配料打印会随之切换。语言选择单独保存在本机浏览器的 `pk-assembly-language` 设置中，不影响已有贴片、备料或计时记录。

## 使用方法

1. 选择与实物一致的板卡版本和电源变体，阅读版本说明与贴装提醒。
2. 打开「备料」，按规格、封装、型号、管位或位号搜索，逐组勾选已备好的料。配料纸按类别和封装摆盘，同一封装内按标称值从小到大排列。网页和配料纸使用相同料位号，位号用于核对。
3. 开始贴片。顶部显示当前料的规格、封装、数量和 BOM 备注；板上高亮当前位号与同料位置，点击元件或右侧位号可定位。
4. 标记已贴或跳过缺料件，使用分类导航切换元件类别，打开「焊接表」逐项核对。

鼠标滚轮缩放、拖拽平移。正反面可切换；数据中带有极性信息的元件会显示阴极或 1 脚提示。换料时弹出换料卡，提示这种料还需贴装的数量。

| 快捷键 | 作用 |
|---|---|
| 空格 | 标记当前件已贴并前进 |
| Enter / A | 将当前组剩余元件标记已贴，进入下一组 |
| Z | 撤销上一次批量标记 |
| ← / Backspace | 退回上一个，同时取消它的已贴标记 |
| → | 前进，不标记 |
| S | 跳过当前件，不计入已贴 |
| P | 打开或关闭备料清单 |
| Tab | 打开或关闭焊接表 |
| F | 切换正反面 |
| 0 | 复位缩放和平移 |
| Esc | 关闭清单 |

备料清单中的空格用于切换当前组的备料勾选并前进，方向键在搜索结果中移动。备料勾选与贴片进度分别记录。

页面还记录操作间隔估算的活跃贴片时间，以及各组耗时；超过五分钟的操作间隔不计入。底栏「重贴」与焊接表「全部清空」会清空贴片进度和计时；「清空备料」只清除备料勾选。

## 编码管盒

- 在版本选择页打开「共享编码管盒」，登记 A1–J10 的 1.8 / 2 mL 管盒。每格只记实物：类型、封装、规格、料号、供料商和数量，不与某块板的 BOM 或物料组关联。同一料可以占多管，同一格换料后直接改身份信息即可。供料商填过的值会变成输入建议，下次点一下就能选。
- 盒面默认按最新一版 BOM（当前 V5.3）排序：先电容、电阻、电感，同一类里先按封装（0402 → 0603 → 0805 → 1206 → 其他），同一封装内按容量从小到大；片式小件（二极管/LED、热敏等 0402/0603/0805）接在电感之后，同封装按型号；规格里用「/」并列颜色的（如 LED 红/黄）按每个颜色各占一管。配料纸、备料清单用同一套顺序，所以料位和管位是同一条线。空格直接显示建议的那一管料，点开就把类型、规格、封装、料号填好，只需要填数量；按 <kbd>Enter</kbd> 入库并顺着盒面走到下一个管位（已入库或已建议摆位的都算，真空格跳过），左右键切换前后管位，切换时会先保存能保存的改动。盘点数量留空表示未知，实盘为零就填 0。
- 旧版本留下的记录会挡住默认摆位时，用顶栏「清空整盒」一次清掉（会先确认，清空后已记的料号和数量无法恢复）。清空后回到按最新 BOM 生成的默认建议，A1 起重新排。
- 用管位、规格、封装或料号搜索。备料卡与换料卡上的「料位」对应配料纸的顺序编号，「管盒」后的 A1–J10 对应实物管位。页面按料号或规格+封装去找管位，规格或封装不符时提示核对，不改变库存。
- 打开备料清单时会落在正在贴的那一组：卡片高亮，卡片上的管位格号一起高亮，照着盒子取料。
- 展开「从本地文件核对库存」，点「下载 CSV 模板」。模板只有中文表头，可用表格软件填写实际管位（A1–J10）、类型（电容、电阻、电感、二极管或热敏）、规格或厂家料号、供料商和本地库存，保存为 UTF-8 CSV 后预览。供料商列填了就更新到该管位，留空则保留原来记的值。库存列填 `0` 表示实盘为零，留空表示未知。也可选择自己的 UTF-8 CSV（可带 BOM），页面识别「本地库存」「实盘数量」等库存列。没填管位的行按顺序放进空位。供应商库存、BOM 用量、已购买和采购数量均不计入实盘。选择文件后的预览不会改动已保存库存。
- 打开「打印管盒」，选择盒顶普通纸索引、盒顶贴纸索引或单管贴纸。盒顶按默认建议摆位印：还没入库的格子也印出该放什么料，每格只有管位、标称容量（小件印型号）、类型和封装，不印数量、料号或盘点状态。盒盖是 130 × 130 mm（10 × 10 格，每格 13 × 13 mm），一张 A4 按 100% 打印即可，不拼接、不提供 A2/A3。填的尺寸超过 A4 可打印范围（289 × 202 mm）会直接提示，不会偷偷缩放到纸宽。单管贴纸只排已登记的管位，宽高按实际贴纸位置填写。先查看预览，打印时选 A4、设为 100%／实际大小、关闭「适合页面」缩放和页眉页脚；印完量一格，应该是 13 × 13 mm。
- 管盒库存由同一浏览器下访问同一地址的所有板卡版本共用。浏览器按协议、主机和端口区分存储。备料和贴装进度不改变实盘数量。

## 进度与个人数据

已贴、跳过、备料勾选和计时保存在本机浏览器的 `localStorage` 中，按板卡版本区分。关闭后重新访问相同站点可以继续；更换浏览器、设备、访问地址或清除站点数据后，不会自动带入原进度。页面不提供账号或云端同步。

历史个人采购批次文件仍由 Git 忽略。库存文件由浏览器直接读取，盘点资料和采购原表由使用者在本机保管。

## 数据结构与维护

- `index.html`：页面、交互与 PCB 图形渲染。
- `i18n-en.js`：版本目录与 BOM 中文显示字段的英文词典。
- `data/index.json`：版本目录，包含每版的 `id`、标题、说明、位号总数和料组数量。
- `data/<id>.json`：对应版本的完整数据，包含板框、元件分组、BOM 参数、位号、正反面、坐标、焊盘轮廓及极性信息。
- `data/tube-extras.json`：不在最新 BOM 里、但盒里仍要留管位的料（例如只在 V4 用的 3.32kΩ、18nH）。这些料和 BOM 里的料一起按类别、封装、容量排序，不接在末尾。

页面按版本 `id` 加载同名 JSON。新增或更新板卡时，应同时核对索引、版本文件、数量和版本说明，确保几何、BOM 与实物版本一致，并为新增或修改的中文标题、说明及 BOM 显示字段补齐 `i18n-en.js` 英文词条；各历史版本保留自身的贴装规则。

板卡数据由 [Pilot Kit Box 硬件工程](https://github.com/naizhao/Pilot-Kit-Box-ESP32-P4) 中的生成工具从对应 PCB 和 BOM 整理。PCB 几何变化后应重新生成对应数据，不能用旧渲染图片代替焊盘坐标；BOM 或选贴规则变化后也应同步更新。页脚显示数据中的源 PCB 日期，便于核对。

维护页面与数据时，请检查位号定位、正反面、极性、同料分组、数量及选贴范围。公开内容仅保留装配所需的技术信息。库存原表、采购批次、库存数量和内部工程资料保留在本机。`scripts/local_inventory.py` 提供静态预览，仅提供页面、语言文件和版本目录中登记的板卡数据。Pages 打包包含静态页面、语言文件和公开板卡资料。

页面、数据和发布脚本在本仓库根目录直接维护。硬件工程生成对应 JSON 后，将索引和版本数据更新到 `data/`，再执行：

```sh
python3 scripts/export_site.py --prepare
python3 -m unittest discover -s tests -v
python3 scripts/export_site.py --publish
```

`--prepare` 先校验全部公开数据，再定向去除 note 中的个人采购记录。`--publish` 校验目标仓库与空暂存区，精确提交公开文件并推送 main；只应在准备正式发布时执行。Pages 从本仓库已提交内容打包，产物 `_build.json` 记录本仓库提交 SHA。切换域名或访问地址会改变 localStorage 的存储空间，原地址的贴片进度不会自动迁移。

本地浏览器回归需要 Node.js、npm 和已安装的 Google Chrome。运行以下命令时，npm 会提供 Playwright JavaScript 测试库，测试直接启动本机 Chrome，并在隔离的浏览器会话中检查盘点、BOM 联动和 PDF 打印。

```sh
npm exec --yes --package=playwright -- sh -c 'NODE_PATH="$(dirname "$(dirname "$(command -v playwright)")")" node --test tests/test_tube_box.cjs'
```
